# archive — history, kept out of the way

Nothing here is needed to run Coal. It is kept for provenance.

| Folder | What it was |
|---|---|
| `legacy/` | earlier packages (`coal`, `coal_n`), internal handover notes, project audits, old tests |
| `legacy/scripts/` | server launchers with hard-coded original paths |
| `legacy/training-scripts/` | overnight training orchestration |
| `neuromorphic/` | the earlier neuromorphic signal track (bench, notebooks, artifacts, demo) |
| `training/` | checkpoints and training corpora — **ignored by git** |
| `scratch/` | one-off `_*.py` probes — **ignored by git** |
